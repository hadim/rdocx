## Caller and contract assessment

The installed quick-xml implementation's `parse_number` recognizes only lowercase `x` as the hexadecimal introducer. Uppercase `X` therefore fails in quick-xml. `decode_one_xml_reference` only reconstructs one reference, delegates to the decoder, and checks for one resulting character.

`reject_store_attribute_value` first refuses literal `<`, then decodes the whole attribute. Escaped less-than remains legal because the literal check precedes decoding. `validate_store_item` checks document position before decoding GeneralRef. Inside the root it decodes that event. CDATA outside the root always refuses. Literal XML whitespace, comments and processing instructions around the root pass through unchanged. Namespace well-formedness is not imposed. The XML Name predicate accepts colon, including repeated colons.

**Contract**: Both direct block move and clone branches call `inner_matches_slot` before delegation. Nested move and clone call `destination_accepts_control` before splicing. Unwrap calls `parent_can_hold` before replacing the shell. `inner_matches_slot` checks boundary text, then recursively treats nested Word controls as transparent under the destination slot. `sdtPr` and `sdtEndPr` are properties, while each `sdtContent` gets the same boundary check. The depth-1 GeneralRef guard treats decoded space, tab, LF and CR as empty. References inside a real child element are not boundary text. These paths match `docs/hld/03-architecture.md:1801` and `docs/hld/10-bindings-spec.md:2588`. B2 identifies the separate publishing admission path that remains inconsistent.

**Atomic refusal**: Still holds for the repaired move, clone, unwrap and store cases. The tests require the expected error substring and equality of complete serialized package bytes. An uppercase payload-boundary reference propagates a decoder error containing `invalid`. Store validation precedes staging. Nested mutations publish only after validation and successful staged reopen. B2 is missing refusal, not a partial mutation after an error.

**OOXML**: Validation does not reserialize accepted store bytes or payloads. The detached Word wrapper supplies `xmlns:w`, and its extraction range accounts for the opening wrapper length. Existing property order and raw slots are retained. Tests accept and compare exact bytes for `<root a:b="1"/>`, `<root a:b:c="1"/>`, predefined entities, decimal and lowercase hexadecimal references, and escaped less-than as `&lt;` and `&#60;`. CDATA and whitespace are distinguished by position. The remaining schema-content violation is B2.
