## D1. Source element scope is not the replacement destination scope

The new code derives `canonical_word_binding` from each Start or Empty element's complete current prefixes (`crates/rdocx-oxml/src/text.rs:12962`, `crates/rdocx-oxml/src/text.rs:13113`). This correctly fixes pass 1's case where a paragraph binds `w` to Word but a run locally binds it to a foreign namespace. Rewritten markers can now receive their own canonical declaration. The actual source run close and resumed run still preserve the original QName and namespace declarations (`crates/rdocx-oxml/src/text.rs:11516`, `crates/rdocx-oxml/src/text.rs:11528`). The source end event is retained and matches that QName (`crates/rdocx-oxml/src/text.rs:13234`).

However, `prefixes` includes declarations on the source element itself. A declaration on an element that is removed cannot establish a binding for replacement elements written at its parent's scope. For example, retain the new test's inherited canonical `w` paragraph and its `q:r xmlns:w="urn:foreign"` result run, but use this valid existing result text:

```xml
<q:t xmlns:w="http://schemas.openxmlformats.org/wordprocessingml/2006/main">old</q:t>
```

Here `q` already means Word. The input text remains a Word element, its local `w` declaration is valid, and the surrounding run still binds `w` to the foreign namespace. The new Start decision sees local canonical `w` and sets the flag to false. The existing-result replacement consumes the original text element and calls `write_field_result_content_with_binding` without its source attributes (`crates/rdocx-oxml/src/text.rs:13054`). That writer emits `w:t`, `w:tab` and `w:br` without a Word declaration when the flag is false (`crates/rdocx-oxml/src/text.rs:13392`, `crates/rdocx-oxml/src/text.rs:13405`, `crates/rdocx-oxml/src/text.rs:13451`). The generated elements therefore inherit the run's foreign `w`, changing or losing the field's Word cached display. This is a direct source-derived correctness finding, not a newly executed test claim.

The same scope distinction matters wherever a source marker or text element supplies a declaration but generated output is emitted as its replacement or outside its original run. Canonical marker rewrites that copy their own declarations and generated sibling output cannot safely share a flag unless it proves the actual destination binding. Fixing only marker names does not establish that proof.

The expanded matrix now covers 24 combinations of source QName, Start or Empty end marker, direct or nested rewriting, and missing or existing results. It includes tabs and newlines and checks saved/reparsed current value, reset default, foreign content and nested parent instruction (`crates/rdocx-oxml/src/text.rs:20114`). Its declarations remain at the paragraph and run levels. The existing `q:t` has no local namespace declaration (`crates/rdocx-oxml/src/text.rs:20128`), so it does not reject the example above.

**Required remediation:** Distinguish the namespace scope of the retained or rewritten source element from that of newly generated replacement siblings. A local source declaration must either be carried onto each generated element that needs it or replaced with an explicit canonical Word declaration there. Preserve foreign namespace meanings and the matched source run QName. Add the existing-result text-local canonical rebind under the foreign run to the current shared matrix, and include marker-local rebinding where insertion changes the output parent. Keep actual semantic reparsing assertions with text, tab and break content. This remains one bounded D1 scope repair, not a request to reopen the whole feature review.
