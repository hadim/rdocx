**Remaining defect:** The decision to declare canonical `w` is based on the stored paragraph prefix inventory rather than the marker's actual namespace scope (`crates/rdocx-oxml/src/text.rs:12953`). That inventory is captured from the paragraph projection when constructing a parsed complex field (`crates/rdocx-oxml/src/text.rs:5936`, `crates/rdocx-oxml/src/text.rs:5943`). A valid paragraph can bind both `w` and `q` to Word, while a source `q:r` locally binds `w` to `urn:foreign`. Such a run and its `q:fldChar` remain Word elements, but the outer flag is false because inherited `w` appears in the paragraph inventory.

On publication the helper deliberately restores the source run's local `xmlns:w="urn:foreign"` (`crates/rdocx-oxml/src/text.rs:11530`). The end marker is then rewritten as `w:fldChar`. `write_rewritten_field_element` only overrides or adds `xmlns:w` when the outer flag is true (`crates/rdocx-oxml/src/text.rs:13279`, `crates/rdocx-oxml/src/text.rs:13291`), even though it receives the actual marker prefixes. With the false flag, the rewritten marker and its new `w:fldCharType` attribute resolve to the foreign namespace. The rewritten begin marker has the same scope problem. Output may be well-formed but no longer describe the same Word field. This is a source-derived defect, not a newly executed failure claim.

The new 12-combination test exercises default, alternate and canonical source run QNames, Start and Empty end markers, and direct and nested rewriting (`crates/rdocx-oxml/src/text.rs:20113`). However, its paragraph root declares only `q` (`crates/rdocx-oxml/src/text.rs:20136`). Its foreign local `w` cases therefore select the true declaration branch. They do not cover a canonical inherited `w` followed by a local foreign shadow. The successful matrix does not reject the wrong behavior above.

**Required remediation:** Determine the declaration needed for rewritten canonical marker names from their actual element scope, including local declarations, or bind canonical `w` explicitly on every rewritten marker while preserving foreign attribute meanings. Retain the actual source run QName and namespace restoration. Extend the same direct/nested and Start/Empty matrix with inherited canonical `w` plus run-local foreign `w`, and verify saved/reparsed typed current value, unchanged reset default and foreign data.
